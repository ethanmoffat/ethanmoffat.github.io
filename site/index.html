eolib

Libraries for writing Endless Online applications. Each library generates its protocol code from the eo-protocol XML specification and has the same API, adapted to the conventions of its language.

  • eolib-cpp

    C++17 library, distributed as a CMake package.

    Documentation GitHub Releases

  • eolib-dotnet

    .NET library, distributed as the Moffat.EndlessOnline.SDK NuGet package.

    Documentation GitHub NuGet

  • eolib-go

    Go module, documented on pkg.go.dev.

    Documentation GitHub
